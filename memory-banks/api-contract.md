When either agent needs a change that crosses the boundary, add it to [Pending Changes](#pending-changes) below.

## POST `/api/taste-profile`

**Request:**
```json
{ "description": "string — free-text description of the recipient" }
```

**Response:**
```json
{
  "tasteProfile": {
    "recipient": { "name": "string|null", "relationship": "string|null" },
    "occasion": "string|null",
    "budget": { "min": "number|null", "max": "number|null" },
    "interests": ["string"],
    "interestAliases": { "interest": ["shopping tokens"] },
    "aesthetic": "string|null",
    "personality": "string|null",
    "constraints": ["string"],
    "giftingContext": "string|null",
    "summary": "string|null",
    "clarification": {
      "question": "string",
      "options": [{ "label": "string", "patch": {} }]
    }
  }
}
```
- `clarification` is `null` when the description is detailed enough.

## POST `/api/recommendations`

**Request:**
```json
{
  "tasteProfile": { "...pre-built taste profile object" },
  "description": "string (optional fallback)"
}
```

**Response:**
```json
{
  "recommendations": [ "...Recommendation objects (see schema below)" ],
  "meta": {
    "curatedFor": "string — recipient name or relationship for heading",
    "summary": "string — rich text summary (supports **bold** markers)"
  },
  "tasteProfile": { "...echo back" }
}
```

## Recommendation Object Schema

This is the contract. Every field listed here must be provided by the backend. The frontend renders based on these fields.

```js
{
  name:              String,        // Product name
  price:             String,        // Display price (e.g., "$49.99")
  description:       String,        // Product description (from enrichment, "" if unavailable)
  brand:             String|null,
  rating:            String|null,   // e.g., "4.7" — prefers merchant-level, falls back to Google aggregate
  tag:               String,        // Category label — "TOP PICK" or "GREAT FIND"
  ctaText:           String,        // Button text — "View Product"
  ctaColor:          String,        // Hex color for CTA — "#c8956c"
  url:               String,        // Purchase link (merchant URL or Google Shopping fallback)
  imageUrl:          String,        // Primary product image
  imageUrls:         String[],      // Thumbnail gallery (empty array if <= 1 image)
  imageBg:           String,        // Fallback background color — "#252220"
  matchedAttributes: [{ label: String, category: String }], // LLM-generated gift-fit pills (1-2 per product)
  merchantBadges:    String[],      // e.g., ["Free Shipping", "30-Day Returns"]
  matchScore:        Number|null,   // 0-100 match confidence score. Derived from prune scoring. Frontend shows MatchRing when >= 85.
  badgeLabel:        String|null,   // e.g., "Best Match", "She'll Love This", "Perfect for Birthday" — rule-based from matchScore + occasion
  badgeType:         String|null,   // One of: "confidence", "social", "occasion" — drives icon + color
  reactionLine:      String|null,   // LLM-generated predicted recipient reaction. null in cache-only mode.
  sourceTag:         String|null,   // "amazon" or null. Drives Amazon badge on frontend.
  socialProof:       String|null,   // e.g., "50+ bought in past month". Amazon social proof text. null for non-Amazon products.
}
```

### Amazon Source Tag
- `sourceTag === 'amazon'` means the product came from Amazon search (not Google Shopping)
- Frontend should show an Amazon-branded pill badge (orange, `#FF9900`) when `sourceTag` is `"amazon"`
- Amazon product URLs already contain the `?tag=giftherai-20` affiliate tag (applied by backend during normalization)
- Amazon products may have additional `merchantBadges` values: `"Prime"`, `"Best Seller"`, `"Amazon's Choice"`

### Social Proof
- `socialProof` is a human-readable string from Amazon (e.g., "50+ bought in past month", "10K+ bought in past month")
- Only present on Amazon products (`sourceTag === 'amazon'`)
- Frontend should render this as subtle secondary text on the card when present

### Badge System
- `badgeLabel` + `badgeType` replace the generic `tag` when both are present
- Types: `"confidence"` (sparkle icon, copper), `"social"` (heart icon, warm-gray), `"occasion"` (gift icon, sage)
- Fallback: when absent, frontend shows `tag` ("TOP PICK" / "GREAT FIND")

### MatchRing
- `matchScore` >= 85 triggers animated copper ring display
- `matchScore` >= 90 adds subtle pulse animation

### Reaction Line
- Italic quote below product name: "She'll use this every morning"
- Generated by LLM alongside pill labels
